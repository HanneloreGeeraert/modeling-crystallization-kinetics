#This modeling code was developed as part of the PhD thesis “Structure–Property Relations and Crystallization Behavior of Poly(3-hydroxybutyrate-co-4-hydroxybutyrate) Biopolymers”, completed at the Vrije Universiteit Brussel (VUB), Brussels, Belgium, in October 2026.

#The structure, implementation, and application of the modeling code are described and discussed in the PhD thesis, in the context of modeling the crystallization behavior of P(3HB-co-4HB) using the Haudin–Chenot crystallization theory.
